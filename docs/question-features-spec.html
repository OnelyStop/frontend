What to build: three features, six tables, and what to pull out of each paper

Every table we need, every field, what it means in plain words, and whether we already have the data or still have to get it.

All the tables

Six tables. Two hold the questions, three record what a student did, one is a running total we keep so we don't recalculate it constantly.

What to pull out of each paper

Run once per JSON file. Ten things.

FROM THE FILE — already there
  1  paper_id           use as-is
  2  bank role          e.g. SBI · PO
  3  exam_type year     Mains · 2019
  4  shift              usually missing, that's fine
  5  source pdf path    keep for tracing

WORK OUT OURSELVES — not in the file
  6  exam_key           bank + role + exam_type + year + shift
                        joined together. Papers sharing a key
                        describe the same real exam.
  7  is_canonical       of the papers sharing an exam_key, mark
                        the most complete one; hide the rest
  8  duration_min       from the exam pattern, not the file
                        (SBI PO Mains = 180, Prelims = 60)
  9  total_marks        same — from the pattern
 10  section_timing     which sections, how long each

What to pull out of each question

Run once per question. Fifteen things, and four of them we don't have yet.

FROM THE FILE — already there
  1  q_id
  2  q_num              its number in the paper
  3  stem               the question text
  4  options            a–e  (98% of the time)
  5  direction_id       which passage, if any

WORK OUT OURSELVES — cheap, do it in the import script
  6  content_hash       hash of stem + options, to spot the same
                        question arriving from two sources
  7  marks              1, from the exam pattern
  8  negative_marks     0.25, from the exam pattern
  9  is_active          false if options are missing or empty

STILL MISSING — real work, not a script
 10  answer             ← nothing works without this
 11  explanation        why the answer is right
 12  section            Reasoning / Quant / English / GA
 13  topic              "Seating arrangement", "Profit & loss"
 14  difficulty         1–5
Items 10–14 are the whole gap. Everything else is a few lines of code in the import script. Answer keys are the one that blocks two of the three features — a timed test that cannot mark itself is not shippable.

The three features

Same questions in all three. What differs is how much time the student has.

01Question Bank 2 minutes
┌──────────────────────────────────────┐ │ Question Bank 12 / 240 done │ │ SBI · PO · Reasoning │ │ │ │ Q. A, B, C, D and E sit in a row… │ │ ( ) 3rd right (•) 5th left │ │ ( ) 2nd left ( ) 3rd left │ │ │ │ [ Check ] Skip → │ └──────────────────────────────────────┘
  • One question at a time. Answer, told right or wrong, next.
  • No clock. Close it mid-question and nothing is lost.
  • Counter is scoped to the filter — 12 / 240, not 12 / 18,651.
