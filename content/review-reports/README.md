# Review reports

One markdown file per subject, written by a reviewer (see
docs/study-module-spec.md §16). Reviewers do not edit another agent's topic
files; they record findings here.

Each report classifies every topic as `PASS`, `PASS_WITH_CHANGES`, or `REJECT`,
and for every problem gives the file, block/card id, evidence URL, severity, and
the required correction.

No reviewer sets `contentStatus` to `published`; a human subject reviewer does
that after the report is addressed.
